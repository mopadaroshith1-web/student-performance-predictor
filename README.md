# Student Performance Predictor

A machine learning project that predicts student final marks using academic factors.

## Features
- Student dataset generation
- Data analysis and visualization
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Model evaluation
- Interactive Streamlit prediction interface

## Input Features
- Study Hours
- Attendance
- Previous Score
- Assignments Score

**Target:** Final Marks

## Technologies
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Streamlit

## Installation

```bash
python -m pip install -r requirements.txt
```

## Run the App

```bash
python -m streamlit run app.py
```

## Validate the Models

```bash
python validate_project.py
```

## Dataset Disclaimer
The included dataset is synthetically generated for demonstration. Performance on synthetic data does not establish accuracy on real students.
